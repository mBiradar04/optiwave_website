Place static images here for the frontend. Public files are served from the root at runtime.

Suggested subfolders:
- /images/hero — hero/banner images (e.g., hero-1.svg, hero-2.svg...)
- /images/products — product images
- /images/clients — logos for clients
- /images/logos — company logos
- /images/placeholders — generic placeholders

Example usage in code: `/images/hero/hero-1.svg` or `/images/placeholder-image.svg`
